# Release Notes

## 3.2 (February 2025)

- Passkey login for the web UI.
- Immutable snapshots using S3 object lock (Enterprise).
- API v1 is deprecated and will be removed in version 4.0.

## 3.1 (September 2024)

- End-to-end encrypted vaults are generally available.
- Webhooks v2 with request signing.

## 3.0 (March 2024)

- New sync engine with block-level delta sync.
- ARM64 server builds.
- 32-bit clients are no longer supported.
