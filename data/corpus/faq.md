# Frequently Asked Questions

## Is Driftbox open source?

The server is source-available under the Business Source License. The desktop and mobile clients
are open source under the Apache 2.0 license.

## Can I run the server on Windows?

No. The server runs on Linux. You can try it on Windows through Docker Desktop for testing, but
that setup is not supported in production.

## Does Driftbox run on a Raspberry Pi?

Yes, any 64-bit ARM board with at least 2 GB of RAM works, because ARM64 builds are available.

## How many devices can one person connect?

Up to 3 devices on Community, unlimited on Team and Enterprise.

## Can I move between plans?

Yes. Upgrades take effect immediately. Downgrades take effect at the end of the billing period.
